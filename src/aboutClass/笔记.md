# 反射

# 一、概念

## 1、什么是反射

java反射是指在**运行状态**中，

-   对于任意一个类，都能够知道这个类的所有属性和方法；   
-   对于任意一个对象，都能够调用这个对象的任意属性和方法； 

  这种动态获取的信息及调用对象的方法的功能称为java语言的反射机制。   

## 2、万物皆对象

### 2、如何获取字节码对象

```java
package com.ylzx.test;

//A依赖B，A负责B的实例化工作
//导包也是依赖的体现
import com.ylzx.entity.User;

public class UserTest {
    public static void main(String[] args) throws ClassNotFoundException {
        //获取字节码对象：三种方式
        //第一种方式：通过对象获取
        User user = new User();
        Class c1 = user.getClass();
        System.out.println(c1);
        //第二种方式：通过类名获取
        Class c2 = User.class;
        System.out.println(c2);
        System.out.println(c2==c1);//比较的是对象的内存地址
        //第三种方式：通过【解耦,推荐】
        Class c3 = Class.forName("com.ylzx.entity.User");
        System.out.println(c3);
    }
}
```



## 5、构造器对象(Constructor)

```java
package com.ylzx.test;

import java.lang.reflect.Constructor;

//通过反射获取构造器对象
public class ConstructorTest {
    public static void main(String[] args) {
        try {
            //第一步：先获取字节码对象
            Class clazz = Class.forName("com.ylzx.entity.User");
            //第二步：获取公有权限的构造器对象
            Constructor constructor1 = clazz.getConstructor(null);
            System.out.println(constructor1);//public com.ylzx.entity.User()
            //获取有参构造器对象
            Constructor constructor2 = clazz.getConstructor(int.class);
            System.out.println(constructor2);
            //获取私有权限的构造器对象
            Constructor constructor3 = clazz.getDeclaredConstructor(int.class, String.class);
            System.out.println(constructor3);

            //构造器对象能干嘛？可以实例化对象
            Object obj = constructor1.newInstance();
            Object obj2 = constructor2.newInstance(18);//参数为实参

            //获取私有的构造器对象
            //暴力访问
            constructor3.setAccessible(true);//设置访问权限
            Object obj3 = constructor3.newInstance(18, "张三");


        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

```

## 6、属性对象(Field)



```java
package com.ylzx.test;

import com.ylzx.entity.User;

import java.lang.reflect.Field;
import java.util.Arrays;

//属性对象
public class FieldTest {
    public static void main(String[] args) {
        try {
            //获取字节码对象
            Class<?> clazz = Class.forName("com.ylzx.entity.User");
            //获取指定的公有属性对象
            Field nameField = clazz.getField("name");
            System.out.println(nameField);
            //获取指定的私有属性
            Field moneyField = clazz.getDeclaredField("money");
            System.out.println(moneyField);
            //获取所有公有权限属性
            Field[] fields = clazz.getFields();
            System.out.println(Arrays.toString(fields));
            //获取所有任意权限的属性
            Field[] declaredFields = clazz.getDeclaredFields();
            System.out.println(Arrays.toString(declaredFields));

            //给属性赋值，参数1：属性所依赖的对象；参数2：属性的实参
            //注意：属性对象需要依赖所在的实例对象
            Object obj = clazz.newInstance();
            nameField.set(obj,"张飞");
            //obj强转
            User user = (User) obj;
            System.out.println(user.name);

        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

```



## 7、方法对象（Method）

```java
package com.ylzx.test;

import java.lang.reflect.Method;
import java.util.Arrays;

//方法对象
public class MethodTest {
    public static void main(String[] args) {
        try {
            //先获取字节码对象
            Class<?> clazz = Class.forName("com.ylzx.entity.User");
            //获取公有权限的方法对象
            Method show1Method = clazz.getMethod("show1");
            System.out.println(show1Method);
            //获取所有公有权限的方法（包含父类的）
            Method[] methods = clazz.getMethods();
            System.out.println(Arrays.toString(methods));
            //获取私有权限的方法
            Method show2Method = clazz.getDeclaredMethod("show2", String.class, double.class);
            System.out.println(show2Method);

            //设置访问权限
            show2Method.setAccessible(true);
            //调用方法，也需要依赖改方法对象所在的类对象
            Object result = show2Method.invoke(clazz.newInstance(), "王富贵", 1000000);
            System.out.println(result);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

```

## 8、案例一：使用配置文件加载对象

1）配置文件：``resources``-``info.properties``

```properties
className=com.ylzx.entity.User
name=王杰
money=100
```

2）测试类

```java
package com.ylzx.test;

import com.ylzx.entity.User;

import java.io.IOException;
import java.io.InputStream;
import java.lang.reflect.Field;
import java.util.Properties;

//案例：通过配置文件，来实例化对象
public class PropertiesTest {
    public static void main(String[] args) throws Exception {
        //可以类加载器加载资源
        InputStream in = PropertiesTest.class.getClassLoader().getResourceAsStream("info.properties");
        //创建一个Properties对象
        Properties pro = new Properties();//键值对
        //加载数据
        pro.load(in);
        //获取数据
        String className = pro.getProperty("className");
        String name = pro.getProperty("name");
        String money = pro.getProperty("money");
        //通过反射，获取字节码对象
        Class<?> clazz = Class.forName(className);
        //获取属性对象
        Field nameField = clazz.getDeclaredField("name");
        Field moneyField = clazz.getDeclaredField("money");
        //设置访问权限
        nameField.setAccessible(true);
        moneyField.setAccessible(true);
        //创建对象
        Object obj = clazz.newInstance();
        //给属性赋值
        nameField.set(obj, name);
        moneyField.set(obj, Double.parseDouble(money));
        //对象强转
        User user = (User) obj;
        //测试
        System.out.println(user.getName());
        System.out.println(user.getMoney());
    }
}
```

## 9、案例二：通过反射绕开泛型检测

```java
package com.ylzx.test;

import java.lang.reflect.Method;
import java.util.ArrayList;
import java.util.List;

//通过反射，绕开泛型检测
public class ListTest {
    public static void main(String[] args) throws Exception {
        List<String> list = new ArrayList();
        list.add("张三");
        //list.add(100);

        //通过反射，绕开泛型检测
        Class clazz = list.getClass();
        //获取指定方法
        Method addMethod = clazz.getDeclaredMethod("add", Object.class);
        //调用方法
        addMethod.invoke(list,100);
        //测试
        System.out.println(list);
    }
}

```

## 10、总结

- 先获取字节码对象   
  -   获取字节码对象的三种方式   
    - 对象.getClass()方法   
    - 类名.class属性   
    - Class.forName("包名.类名") **推荐使用**

- 通过反射获取构造方法   
  - Constructor<?>[] getConstructors() 获取所有公有构造方法   
  - Constructor<?>[] getDeclaredConstructors() 获取所有构造方法（公有、私有、受保护、默认）   
  - Constructor<T> getConstructor(Class<?>... parameterTypes) 获取单个公有构造方法   
  - Constructor<T> getDeclaredConstructor(Class<?>... parameterTypes) 获取单个任意构造方法（公有、私有、受保护、默认）   
  - 创建实例：constructor.newInstance(Object... initargs)  
- 通过反射获取成员变量    
  - Field[] getFields() 获取所有公有成员变量   
  - Field[] getDeclaredFields() 获取所有成员变量（公有、私有、受保护、默认）   
  - Field getField(String name) 获取单个公有成员变量   
  - Field getDeclaredField(String name) 获取单个任意成员变量（公有、私有、受保护、默认）
  - 给属性赋值：  field.set(Object obj, Object value)   
    - obj：该属性所依赖的对象，比如stu   
    - value：属性值   

- 通过反射获取方法   
  - Method[] getMethods() 获取有公有方法（包括父类的）
  - Method[] getDeclaredMethods() 获取所有方法（公有、私有、受保护、默认，仅限自己的）   
  - Method getMethod(String name, Class<?>... parameterTypes) 获取单个公有方法   
  - Method getDeclaredMethod(String name, Class<?>... parameterTypes) 获取单个任意方法（公有、私有、受保护、默认）
  - 调用方法：  Object result= method.invoke(Object obj, Object... args) ;   
    - obj：该方法所依赖的对象，比如stu   
    - args：方法中的实参
    - result：方法执行后的返回结果
-   私有权限需要设置：setAccessible(**true**);
